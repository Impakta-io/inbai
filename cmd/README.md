# Commands

`inbai` is the operator CLI. With no arguments it prints its version. `inbai init` bootstraps Stalwart, `inbai domain add` prints that domain's DNS records, and `inbai doctor` checks the host. The other commands are listed in the [CLI guide](../docs/guides/cli.md). `inbaid` is the server. `inbaid serve` runs the REST API and MCP, and `inbaid version` prints its version.

Shared version text lives in `internal/version`.
