# ADR 0001: Record architecture decisions

- Status: accepted
- Date: 2026-11-23

## Context

Contributors need to know why the design is what it is, including people who arrive later and people using coding agents.

## Decision

Significant decisions are written as records in `docs/adr`. A record is accepted, proposed, or replaced. A replaced record stays in the tree, and the newer record links to it. The process for opening a decision is in [proposals.md](../contributing/proposals.md).

## Consequences

A design change has a durable explanation. Records can go stale if nobody writes them, so an accepted proposal is not done until its record is merged.
