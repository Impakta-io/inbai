### inbai init

Set up Stalwart, PostgreSQL, the domain, and config.json.

```text
inbai init --domain name [--public] [--no-docker] [--url url] [--api-url url] [--hostname name] [--stalwart-url url] [--stack-dir dir] [--config path] [--json]
```

With Docker Compose, init writes a stack into &lt;config-dir&gt;/stack, starts PostgreSQL and Stalwart, bootstraps the domain, and writes config.json with mode 0600. Ports bind to loopback unless --public is given.

With --url or --no-docker, init bootstraps a Stalwart that is already running, using INBAI_RECOVERY_PASSWORD. Running init again keeps the domain, accounts, passwords, tokens, and retention already saved.

Flags:

```text
  -api-url string
    	inbaid API URL to store for later commands (default: keep the stored one, else http://127.0.0.1:8787)
  -config string
    	config file to write (default inbai/config.json in the user config directory)
  -domain string
    	DNS domain to create
  -hostname string
    	mail hostname (default mail.<domain>)
  -https-port int
    	Stalwart HTTPS port in Docker mode (default 8443, or 443 with --public)
  -json
    	print JSON
  -no-docker
    	connect to an already-running Stalwart instead of starting Docker Compose
  -pg-port int
    	local PostgreSQL port in Docker mode (default 5433)
  -public
    	bind SMTP (25) and HTTPS (443) on all interfaces in Docker mode
  -recovery-port int
    	Stalwart recovery port in Docker mode (default 8080)
  -smtp-port int
    	Stalwart SMTP port in Docker mode (default 2525, or 25 with --public)
  -stack-dir string
    	directory for local Docker Compose files (default <config-dir>/stack)
  -stalwart-url string
    	Stalwart URL to store for later commands
  -submission-port int
    	deprecated and ignored: inbAI does not publish SMTP submission
  -url string
    	Stalwart recovery API, reachable on the host (skips local Docker setup) (default "http://127.0.0.1:8080")
```

Environment:

| Variable | Meaning | Default |
| --- | --- | --- |
| `INBAI_RECOVERY_PASSWORD` | Stalwart recovery password; selects external mode |  |
| `INBAI_OPERATOR_TOKEN` | operator token, when the config has none yet |  |
| `COMPOSE_PROJECT_NAME` | Docker Compose project name |  |

Examples:

```sh
inbai init --domain example.com
inbai init --domain example.com --public
INBAI_RECOVERY_PASSWORD=... inbai init --url http://127.0.0.1:8080 --domain example.com
```

### inbai doctor

Check DNS, reverse DNS, port 25, TLS, and blocklists.

```text
inbai doctor [--domain name] [--config path] [--tls-insecure] [--json]
```

doctor checks the MX and TXT records Stalwart publishes, reverse DNS, port 25, TLS on port 443, and the Spamhaus ZEN and SpamCop blocklists. It exits 0 when every check passes and 1 when one needs a fix.

Flags:

```text
  -config string
    	config file written by inbai init
  -domain string
    	domain to check (default is the domain in the config file)
  -json
    	print JSON
  -tls-insecure
    	skip TLS verification for a server that is not on localhost
```

Examples:

```sh
inbai doctor
inbai doctor --json
```

### inbai domain relay

Send mail for other domains through an SMTP relay.

```text
inbai domain relay --host name --user name [--port n] [--config path] [--json]
inbai domain relay --off [--config path] [--json]
```

Mail for a domain this server hosts stays local. --off sends other domains to their MX hosts again. The command signs in to Stalwart as operator@&lt;domain&gt;.

Flags:

```text
  -allow-invalid-certs
    	accept a relay certificate that does not validate
  -config string
    	config file written by inbai init
  -host string
    	SMTP relay host name
  -implicit-tls
    	use TLS from the first byte, as on port 465
  -json
    	print JSON
  -off
    	deliver other domains by MX instead of a relay
  -port int
    	SMTP relay port (default 587)
  -tls-insecure
    	skip TLS verification for a server that is not on localhost
  -user string
    	SMTP relay user name
```

Environment:

| Variable | Meaning | Default |
| --- | --- | --- |
| `INBAI_RELAY_PASSWORD` | SMTP relay password |  |
| `INBAI_OPERATOR_PASSWORD` | operator password (default the one init stored) |  |
| `INBAI_RECOVERY_PASSWORD` | used when neither of the above is set |  |

Examples:

```sh
INBAI_RELAY_PASSWORD=... inbai domain relay --host smtp.example.net --user mailer
inbai domain relay --off
```

### inbai inbox create

Create one inbox address.

```text

```

The address is &lt;local-part&gt;@&lt;domain&gt; for the config domain. The address and its account id are written into the config file, which the message commands read.

Flags:

```text

  -json

  -quota-bytes int

```

Flags go before arguments. Flag parsing stops at the first argument.

Examples:

```sh
inbai inbox create alice
inbai inbox create --quota-bytes 52428800 bob
```

### inbai login

Check credentials and save them in the config file.

```text
inbai login [--url url] [--client-id id] [--clear] [--config path] [--json]
```

With --client-id (or INBAI_CLIENT_ID) and INBAI_CLIENT_SECRET, login checks and stores the client credentials, which later commands use before operatorToken. Otherwise it checks and stores INBAI_OPERATOR_TOKEN and removes stored client credentials. --clear removes the stored client credentials only.

Flags:

```text
  -clear
    	remove stored client credentials from config (operatorToken is kept)
  -client-id string
    	OAuth client id (uses INBAI_CLIENT_SECRET)
  -config string
    	config file (default inbai/config.json in the user config directory)
  -json
    	print JSON
  -url string
    	inbaid API URL (default config apiUrl or http://127.0.0.1:8787)
```

Environment:

| Variable | Meaning | Default |
| --- | --- | --- |
| `INBAI_OPERATOR_TOKEN` | operator token to store |  |
| `INBAI_CLIENT_ID` | OAuth client id, instead of --client-id |  |
| `INBAI_CLIENT_SECRET` | OAuth client secret |  |

Examples:

```sh
INBAI_OPERATOR_TOKEN=... inbai login --url https://inbai.example.com
INBAI_CLIENT_SECRET=... inbai login --client-id <client-id>
inbai login --clear
```

### inbai retention

Print or set how many days mail is kept.

```text
inbai retention [--days n] [--inbox id] [--config path] [--json]
```

--days 0 keeps mail. With --inbox, only that inbox changes. inbaid deletes older mail about once an hour.

Flags:

```text
  -config string
    	config file
  -days int
    	days to keep mail, or 0 to keep it (default -1)
  -inbox string
    	inbox id, or empty for the server default
  -json
    	print JSON
```

Examples:

```sh
inbai retention
inbai retention --days 14
inbai retention --inbox <inbox-id> --days 7
```

Flags:

```text

    	config file
```

Environment:

| Variable | Meaning | Default |
| --- | --- | --- |
| `INBAI_ACCESS_TOKEN` | access token to use as is |  |
| `INBAI_CLIENT_ID` | OAuth client id |  |
| `INBAI_CLIENT_SECRET` | OAuth client secret |  |
| `INBAI_OPERATOR_TOKEN` | operator token |  |

Examples:

```sh
inbai mcp serve
inbai mcp serve --config /etc/inbai/agent.json
```

Server for inbAI, self-hosted email for AI agents: the REST API, MCP, and workers.

| Command | Summary |
| --- | --- |
| [`inbaid serve`](#inbaid-serve) | Run the REST API, MCP, and background workers |
| [`inbaid version`](#inbaid-version) | Print the version |
| [`inbaid help`](#inbaid-help) | Show help for a command |

### inbaid serve

Run the REST API, MCP, and background workers.

```text
inbaid serve [--addr host:port] [--config path]
```

In Stalwart mode, the default, serve reads the config file inbai init wrote. With INBAI_MAIL=imap it reads only the environment, needs INBAI_OPERATOR_TOKEN, and uses an existing IMAP and SMTP server.

Without a database, jobs, quota counters, and the signing key live in this process only. Environment variables override the config file. A bad value stops startup with exit code 2.

Flags:

```text
  -addr string
    	listen address (default "127.0.0.1:8787")
  -config string
    	config file (default inbai/config.json in the user config directory)
```

Environment:

| Variable | Meaning | Default |
| --- | --- | --- |
| `INBAI_OPERATOR_TOKEN` | Core: operator token | operatorToken in config |
| `INBAI_SIGNING_KEY` | Core: signing key, 32+ bytes | stored, or random |
| `INBAI_INGEST_SECRET` | Core: secret Stalwart sends to /v1/hooks/ingest |  |
| `INBAI_STALWART_URL` | Core: Stalwart URL | stalwartUrl in config |
| `INBAI_TLS_INSECURE` | Core: 1 skips Stalwart certificate checks |  |
| `INBAI_DATABASE_URL` | Database: PostgreSQL URL | databaseUrl in config |
| `INBAI_MAIL` | Mail mode: imap uses IMAP and SMTP instead of Stalwart |  |
| `INBAI_DOMAIN` | IMAP mode: mail domain (required) |  |
| `INBAI_IMAP_ADDRESS` | IMAP mode: IMAP host:port (required) |  |
| `INBAI_SMTP_ADDRESS` | IMAP mode: SMTP host:port (required) |  |
| `INBAI_IMAP_ACCOUNTS` | IMAP mode: account file, JSON (required) |  |
| `INBAI_IMAP_SECURITY` | IMAP mode: tls, starttls, or none | by port |
| `INBAI_SMTP_SECURITY` | IMAP mode: tls, starttls, or none | by port |
| `INBAI_ALLOW_PLAINTEXT_AUTH` | IMAP mode: 1 allows none to a remote host |  |
| `INBAI_IMAP_TLS_INSECURE` | IMAP mode: 1 skips IMAP and SMTP certificate checks |  |
| `INBAI_AUTHSERV_ID` | IMAP mode: authserv-id of trusted Authentication-Results |  |
| `INBAI_IMAP_TLS` | IMAP mode: deprecated; 1 means tls for both |  |
| `INBAI_QUOTA_INBOX_DAILY` | Limits and quotas: daily sends per inbox | 50 |
| `INBAI_QUOTA_DOMAIN_DAILY` | Limits and quotas: daily sends per sender domain | 500 |
| `INBAI_QUOTA_WORKSPACE_DAILY` | Limits and quotas: daily sends per workspace | 5000 |
| `INBAI_RATE_RECIPIENT_PER_MINUTE` | Limits and quotas: per recipient domain | 30 |
| `INBAI_STORAGE_QUOTA_BYTES` | Limits and quotas: storage per new inbox | 104857600 |
| `INBAI_WEBHOOK_WORKERS` | Webhooks: concurrent posts, 1 to 256 | 16 |
| `INBAI_WEBHOOK_ALLOW_PRIVATE` | Webhooks: true allows http and private addresses |  |
| `INBAI_EVENT_RETENTION_DAYS` | Retention: days to keep events, 0 keeps | 30 |
| `INBAI_DELIVERY_RETENTION_DAYS` | Retention: days to keep deliveries | 7 |
| `INBAI_RETENTION_DAYS` | Retention: IMAP mode mail retention days | 0 |

Examples:

```sh
inbaid serve
inbaid serve --addr 0.0.0.0:8787
INBAI_MAIL=imap INBAI_DOMAIN=example.com ... inbaid serve
```

### inbaid help

Show help for a command.

```text
inbaid help [<command> [<subcommand>]]
```

With no command, help lists every command. inbaid &lt;command&gt; --help and -h print the same text as inbaid help &lt;command&gt;. inbaid help --json prints the command table as JSON for tools.

Examples:

```sh
inbaid help
inbaid help serve
```
