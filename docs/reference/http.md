# HTTP reference

| Method | Path | Operation | Summary |
| --- | --- | --- | --- |
| `POST` | `/oauth/token` | `oauthToken` | Exchange a client id and secret for an access token. |
| `POST` | `/v1/agents` | `createAgent` | Create a client credential. The secret is shown once. |
| `POST` | `/v1/grants` | `createGrant` | Grant one permission on one inbox to an agent. |
| `POST` | `/v1/agents/{name}/suspend` | `suspendAgent` | Stop an agent from exchanging a secret or using an access token. |
| `DELETE` | `/v1/grants/{agent}/{inbox}/{permission}` | `revokeGrant` | Remove one permission. A grant that is already gone is still a success. |
| `GET` | `/v1/audit` | `listAudit` | List operator actions for agents, grants, and inboxes. |
| `GET` | `/v1/retention` | `getRetention` | Read how many days the server or one inbox keeps mail. Zero keeps mail. |
| `PUT` | `/v1/retention` | `setRetention` | Set how many days the server or one inbox keeps mail. Zero keeps mail. |
| `POST` | `/v1/retention/run` | `runRetention` | Delete mail older than the retention period. A message with no received time is kept. |
| `POST` | `/v1/inboxes` | `createInbox` | Create one inbox in the configured domain. |
| `GET` | `/v1/inboxes` | `listInboxes` | List accounts in the mail backend. An operator token is required. |
| `DELETE` | `/v1/inboxes/{id}` | `deleteInbox` | Delete one account. An operator token is required. |
| `GET` | `/v1/inboxes/{id}/allowlist` | `getAllowlist` | Read the sender allowlist for one inbox. |
| `PUT` | `/v1/inboxes/{id}/allowlist` | `setAllowlist` | Replace the sender allowlist for one inbox. An empty list removes it. |
| `POST` | `/v1/inboxes/generate` | `generateInboxes` | Create many inboxes. More than 50 addresses returns a job. |
| `GET` | `/v1/jobs/{id}` | `getJob` | Read a bulk-create job. |
| `GET` | `/v1/inboxes/{id}/messages` | `listMessages` | List messages in an inbox. A q query parameter searches text. |
| `POST` | `/v1/inboxes/{id}/messages` | `sendMessage` | Submit a plain-text message as the inbox. |
| `GET` | `/v1/inboxes/{id}/messages/{messageId}` | `getMessage` | Read one message, including its plain-text body and threading headers. |
| `DELETE` | `/v1/inboxes/{id}/messages/{messageId}` | `deleteMessage` | Delete one message. |
| `GET` | `/v1/inboxes/{id}/messages/{messageId}/attachments/{blobId}` | `downloadAttachment` | Download one attachment. The caller needs a read grant. |
| `POST` | `/v1/inboxes/{id}/messages/{messageId}/reply` | `replyMessage` | Reply to one message. The server sets In-Reply-To and References. |
| `GET` | `/healthz` | `health` | Process is running. |
| `GET` | `/readyz` | `ready` | Dependencies answer. The event database is pinged when INBAI_DATABASE_URL is set. |
| `GET` | `/metrics` | `metrics` | Prometheus text for the event feed. |
| `POST` | `/v1/hooks/ingest` | `ingestHint` | Stalwart message-ingest hint. The recipient address selects the inbox. The numeric account id is ignored. |
| `GET` | `/v1/events` | `listEvents` | Long-poll mail changes after a consumer cursor. |
| `GET` | `/v1/suppressions` | `listSuppressions` | List recipients suppressed after a permanent delivery failure. |
| `POST` | `/v1/webhooks` | `createWebhook` | Register a signed webhook. The secret is shown once. |
