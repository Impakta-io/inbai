# Security

Report a vulnerability in private. Do not open a public issue, and do not describe the problem in a pull request.

Use a [GitHub private security advisory](https://github.com/Impakta-io/inbai/security/advisories/new).

Include what is affected, how to reproduce it, and the impact you expect. The maintainers listed in [GOVERNANCE.md](GOVERNANCE.md) will acknowledge the report and agree on a fix before anything is disclosed.

The binaries in this repository do not send or store mail yet. A report about the intended mail design is still welcome if it describes a concrete flaw.
